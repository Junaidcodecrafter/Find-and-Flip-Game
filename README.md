🃏 Find and Flip Game
Find and Flip Game is an engaging, interactive memory-matching web application designed to test and improve cognitive recall. Players are challenged to flip cards and find matching pairs in the shortest amount of time and with the fewest moves possible.

Built with clean architecture and responsive design, this project serves as a fun browser game and a showcase of modern front-end development principles.

✨ Features
Classic Memory Mechanics: Flip cards two at a time to uncover matching pairs.

Move Counter & Timer: Tracks the number of turns taken and the time elapsed to add a competitive edge.

Dynamic Grid Generation: The game board is dynamically generated, ensuring a unique shuffle and layout for every new game.

Interactive UI/UX: Smooth CSS animations for card flipping and matching feedback (success/error states).

Responsive Design: Fully optimized for both desktop and mobile screens.

Win State & Reset: Congratulatory modal upon game completion with a quick-reset feature to play again.

🛠️ Technologies Used
HTML5: Semantic structure for the game board and UI elements.

CSS3: Styling, grid layouts, and smooth 3D flip animations.

JavaScript (ES6+): Core game logic, DOM manipulation, event handling, and state management.

🎮 How to Play
The game starts with all cards face down.

Click on any card to flip it over and reveal its hidden icon/image.

Click on a second card to try and find the matching icon/image.

If the cards match, they will remain face up.

If they do not match, they will automatically flip back over after a short delay.

Remember the positions of the cards and continue until all pairs are matched.

Try to beat your own record by completing the game in fewer moves and less time!
